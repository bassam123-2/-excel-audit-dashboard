# Sample workbooks

Place a **small, anonymized** `.xlsx` here so new developers can test without a production file.

Requirements for the sample:

- Include the required columns listed in [docs/EXCEL_SCHEMA.md](../docs/EXCEL_SCHEMA.md)
- Prefer 10–20 rows instead of hundreds
- Remove real names, emails, and confidential text

Suggested name: `sample_audit_register.xlsx`

This folder is optional; the app does not load files from here automatically.
